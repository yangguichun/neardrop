# 近传 使用说明

一个只在你自己家 Wi-Fi 里跑的传输工具。电脑上做好的短视频文案、图片、视频，直接丢到闲置手机，用那台手机上的抖音发出去。手机拍的东西也能传回来。

不经过微信、不经过任何服务器，文件就存在你自己电脑里。

---

## 零、这东西是为什么做的

我手上有电脑、主力手机、一台专门用来发抖音的闲置手机，品牌还不一样（Windows、华为、荣耀、红米）。每天的工作流是：电脑上剪好视频、写好文案 → 传到闲置手机 → 用那台手机发抖音；手机在外面拍的素材，还得传回电脑再加工。

试过的办法都不合适：

- **微信 / QQ**：要过服务器，视频被压缩，还得切账号
- **网盘**：上传再下载，几百兆等半天，免费还限速
- **LocalSend / 快传**：要求两台设备**同时开着、同时点确认**。手机在充电没解锁就传不过去，传完也没记录
- **各种多端协同软件**：基本要付费订阅，或者只能在自己品牌的生态里用

所以干脆自己写了一个。目标就一句话：**把家里所有设备连成一个只在自家 Wi-Fi 里存在的群，像用微信一样方便，但数据不出门、不要钱、不限速、不压缩。**

### 它和「点对点传输工具」最大的不同

普通传输工具是 A 递给 B，递完就完事。近传是**以你的电脑为中转**：

```
电脑（中转站，消息和文件都存这里）
   ├── 主力手机
   ├── 闲置手机（发抖音）
   └── 平板 / 任何设备
        都在同一个 Wi-Fi 里
```

多这一层，就多了这些能力：

| 特点 | 具体是什么 |
|---|---|
| **异步** | 发完就关手机。对方没开机也不影响，上线自动补收；电脑重启消息也还在 |
| **有历史** | 所有消息和文件永久保留，能往回翻，不在这一台手机上也看得到 |
| **一对多** | 「公共频道」发一次，所有设备都收到；「私聊」只发给某一台 |
| **跨品牌** | 只认浏览器协议，不认厂商。Windows、安卓、鸿蒙、iPad 一视同仁 |
| **原样传输** | 不压缩、不限大小、不需要账号、不收费 |
| **存进相册** | 手机点「保存」，图片视频直接进系统相册，抖音选素材能选到 |
| **换网络不用重配** | 认的是设备不是 IP。家里配好，搬到公司换 Wi-Fi，自动连回来不用再输码 |
| **私有** | 数据只在你家电脑的硬盘上，没有云端、没有第三方 |

## 一、电脑端（只装一次）

1. 把 **「近传 NearDrop」整个文件夹**放到一个固定位置（比如 `D:\近传 NearDrop\`），别只把 exe 单独拷出来——它要靠同目录下的 `_internal` 文件夹才能跑
2. 双击文件夹里的 **NearDrop.exe**
3. Windows 弹出防火墙提示 → **勾上「专用网络」，点「允许访问」**（这一步必须做，不然手机连不进来）
4. 会先弹出一个蓝色的「正在启动」小窗，等几秒到十几秒（看电脑快慢），窗口自己消失、浏览器打开界面，右下角任务栏出现蓝色图标

> 启动慢是正常的：程序要把服务端跑起来，中途那个小窗就是告诉你「还在启动，别急」。如果小窗卡住超过 1 分钟没消失，去 `%LOCALAPPDATA%\NearDrop\neardrop.log` 看最后几行。

> 建议：右键 `NearDrop.exe` → 发送到 → 桌面快捷方式，以后从桌面点就行。

鼠标放到托盘图标上，会显示地址和访问码，形如：

```
http://192.168.1.10:8787   访问码 758302
```

右键托盘图标可以：

- **开机自动启动** —— 建议勾上，以后开机它自己在后台跑，不用管
- 复制地址、复制访问码、打开数据文件夹、退出

> **访问码**是第一次启动时自动生成的 6 位数字，存在数据目录里，重启不变。它的作用是挡住同一个 Wi-Fi 下的其他人——没有码就进不来。电脑本机打开界面不需要码。

## 二、手机端

1. 把 **近传_1.0.5.apk** 发到手机装上（允许"未知来源应用"）
2. 打开 App，它会自动在 Wi-Fi 里找电脑，点一下那个条目
3. 输入电脑上的 **6 位访问码**（托盘菜单里有，界面右上角「👥」里也有）
4. 找不到电脑就手动输入地址，比如 `192.168.1.10:8787`

装好之后，手机和电脑就通了。**之后打开 App 会直接进界面，不用再输码。**

而且这次是**认设备**的：家里配好之后，把电脑和手机一起拿到公司、换成另一个 Wi-Fi，只要三者还在这同一个局域网里，App 会自己找回来直接进，不会再问你访问码——除非你在电脑端把它「移出」了。

> 每台设备有自己的固定编号（存在 App 的私有目录里，清缓存、重装都还在），电脑那一端记着「这台设备验证过」。所以换 IP、换 Wi-Fi 都不影响，只有换电脑或者被移出才需要重新输码。

## 三、怎么用

**左边**是会话列表：

- **公共频道** —— 发一次，所有设备都能收到（电脑做好素材，两台手机都能拿）
- **某某手机** —— 私聊，只发给那一台

**右上角「👥」是设备列表**，能看到：

- **我的地址** —— 这台手机当前的内网 IP
- 每一台设备的**名字、IP、状态**
- 状态标签「在线·可信」= 这台设备输过访问码，换网络会自动连
- 最下面是这台**中转站电脑**的地址，以及访问码

**怎么删掉不用的设备**：已经离线、以后不用的设备（旧手机、重装前的记录），右边有红色「删除」。点一下确认即可 —— 它的记录和登录凭证一起清掉，列表不再挂着；聊天记录会保留，只是发送者显示成「已移除设备」。在线设备不能删（避免误删正在用的），只能在电脑端「移出」。

在**电脑上**打开这个面板（`127.0.0.1`），在线的设备右边多一个「移出」：移出后它必须重新输访问码才能连回来。换了手机、送人了、不想让它再自动连，就用这个。

**点设备行**（点名字那一行任意位置）就进私聊，不用再找按钮。

> 两台手机之间不需要互相直连：它们各自连到电脑，电脑转发。所以只要两台手机都能连上同一台电脑，就能互发。

**发东西**：点输入框左边的 `＋`

| 按钮 | 用途 |
|---|---|
| 图片 | 从相册选，可多选 |
| 视频 | 从相册选 |
| 文件 | 任意文件 |
| 拍照 | 直接拍 |
| 🎙 | 录音，录完点「发送」 |

电脑上还可以**直接把文件拖进窗口**，或者 **Ctrl+V 粘贴截图**。

**收东西**：文件消息下面有「保存」

- 手机 App 里点「保存」→ 图片、视频存进**相册里的「相机」**（文件路径 `内部存储/DCIM/Camera/`），打开抖音就能选到
- 其他文件（word、压缩包等）→ 存到 `内部存储/Download/近传/`
- 电脑上点「保存」→ 下载到电脑
- 图片点一下可以全屏看

> 1.0.4 及更早版本把图片存在 `Pictures/近传`、视频存在 `Movies/近传`，华为/荣耀图库经常扫不到这些目录，表现就是"提示保存成功但相册里没有"。1.0.5 起统一存到系统相机目录，图库必然可见。之前存过的旧文件不会消失，去「文件管理」按上面路径能找到。

**重要**：电脑关机了、手机没开机，消息都不会丢。发出去的东西一直在电脑上存着，哪台设备上线就自动补收。

## 四、文件存在哪

```
C:\Users\你的用户名\AppData\Local\NearDrop\
├── neardrop.db     所有聊天记录
├── files\          所有原始文件
├── thumbs\         缩略图
└── neardrop.log    出问题时的日志
```

备份就把这个 `NearDrop` 文件夹整个拷走。

托盘右键 →「打开数据文件夹」可以直接打开。

## 五、连不上的排查顺序

0. **先等 5 秒**
   App 发现连不上会自动退回扫描页，再等它搜一轮，常常就好了（换了网络、电脑 IP 变了都是这种情况）

1. **手机和电脑是不是同一个 Wi-Fi？**
   手机别用流量，也别连「访客网络」（访客网络通常隔离设备）

2. **防火墙放行了吗？**
   控制面板 → Windows Defender 防火墙 → 允许应用通过防火墙 → 找到「近传」或「NearDrop」，专用网络打勾

3. **路由器开了「AP 隔离」吗？**
   很多路由器默认开启，开了之后同一 Wi-Fi 的设备也互相看不见。去路由器后台关掉（一般在「无线设置」里）

4. **还是不行就直接输地址**
   用托盘里显示的 `192.168.1.10:8787`，手动填进去。这是最稳的方式

## 六、常见问题

**Q：为什么语音要用 App，不能在手机浏览器里录？**
浏览器的规定：非 HTTPS 页面不允许调用麦克风。App 里用的是系统原生录音，没这个限制。

**Q：视频保存了，抖音里还是找不到？**
如果你用的是手机浏览器（不是 App），视频会存到「下载」目录，相册里看不到。装 App 就好了，App 里保存是直接进相册的。

**Q：华为 / 荣耀手机点了「保存」，提示存到相册了，但相册里翻不到？**
1.0.4 及更早版本的 bug：那时图片存在 `Pictures/近传`、视频存在 `Movies/近传`，**华为图库不索引这种二级子目录**，所以"保存成功但看不见"。
**装 1.0.5 即可**，改成存到系统相机目录 `DCIM/Camera`，图库「相册 → 相机」里必定能看到，抖音选素材也能选到。

旧版本存过的文件没丢，只是不在图库里。想看的话用「文件管理」按路径找：
- 图片：`内部存储/Pictures/近传/`
- 视频：`内部存储/Movies/近传/`

**Q：设备列表里那台旧手机再也不用了，怎么从列表里去掉？**
它的状态是「离线」时，右边有红色「删除」，点一下确认就清掉了。在线设备只能在电脑端「移出」（会断开它的连接并让它重新输访问码）。

**Q：点了 `＋` 里的图片 / 视频 / 文件，什么都没弹出来？**
这是 1.0.0 的 bug：App 没有接管网页里的文件选择框，所以点击是静默无效的。**装 1.0.2 即可**，直接覆盖安装，聊天记录不受影响。

**Q：发图片 / 视频 / 文件提示「发送失败 HTTP 401」？**
这是 1.0.3 及更早版本的 bug：文字消息走的是统一请求（带着登录凭证），但传文件用的是另一条通道，**漏带了凭证**，于是被电脑当成陌生设备拒绝。跟文件大小无关，多大都传不上去。
**装 1.0.4 即可**，覆盖安装。装好后传视频会正常显示进度条，传完对方立刻收到。

**Q：电脑重启后，手机还要重新连吗？**
不用。地址不变，App 会自动重连。

**Q：电脑换网络了（比如从家里带到公司），手机一直显示「连接中」？**
1.0.3 起基本不用管了：App 启动后等 5 秒还连不上旧地址，会**自动跳回扫描页**，找到那台电脑（靠的是电脑的固定编号，不是 IP）就**直接连进去，不再问访问码**，因为这台手机上次验证过。

**Q：为什么改完名字，过一会儿又变回「安卓手机」了？**
1.0.2 及更早的 bug：名字只在这次打开的页面里有效，一旦访问码重新验证，服务端又用默认名把它覆盖了。1.0.3 改成「用户改过的名字以本地为准」，改名后先存在手机上，再同步给电脑，网络抖动也不会丢。

**Q：设备身份是怎么认的？能不能用 MAC 地址？**
安卓 10 以后系统不允许 App 读真实 MAC（读出来是 `02:00:00:00:00:00`），所以用了两层：
- App 自己生成一个 UUID 存在私有目录，卸载重装才可能变；
- 再加一个系统的 `ANDROID_ID` 作为找回依据，清缓存重装后还能认回同一台。

电脑那边发一张长期「设备凭证」，和电脑的固定编号绑着存。所以换 IP、换 Wi-Fi 都不影响。

**Q：两台手机能互相发东西吗？怎么发现对方？**
能。两台手机都连到同一台电脑后，各自在「👥」设备列表里就能看到对方（名字 + IP + 在线状态），点「发消息」直接私聊。消息不经过互联网，是电脑转发的。

**Q：访问码忘了 / 想换一个？**
电脑端界面 → 右上角「⚙」设置里能看到当前访问码，点「换一个」可以重新生成。**换码只影响新设备**，已经连上的设备不受影响。

**Q：同一个 Wi-Fi 下的同事能偷看吗？**
没有访问码连不进来，接口全部要令牌校验。要说明的是：这是家用级防护，挡的是"随手连一下"的人；局域网内如果有人刻意做深度攻击，这套东西不负责防（真正的加密需要上 HTTPS 证书，代价是这个工具会难用很多）。

**Q：能在外网用吗（比如在公司给家里的电脑发东西）？**
目前只做局域网。外网需要内网穿透，是另一套东西，暂时没做。
