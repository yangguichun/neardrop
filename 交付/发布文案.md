## 二、正文（主版本，约 300 字）

起因很简单：我手上是 Windows 电脑 + 华为 + 荣耀 + 红米，几个品牌各管各的，自带的互传只认自家人。

每天剪好的视频要丢到闲置手机上发抖音，拍到的素材又得回收电脑再加工，一天来回好几趟。微信传要过服务器、压画质；网盘上传下载两遍，几百兆等半天；LocalSend 这类点对点工具方向是对的，但两台设备必须同时开着、同时点确认——手机在充电没解锁，就传不过去，传完也没留下任何记录。

所以我干脆自己写了一个：让电脑当"中转站"，其他设备连到同一个 Wi-Fi 就自己回来。

- 发完就能关，谁上线谁收，消息不丢
- 历史记录一直在，重启电脑也能翻
- 公共频道群发，也能指定只发给某台
- 手机收到的视频直接进相册，抖音选素材直接能选
- 换 Wi-Fi 不用重新配对，认设备不认 IP

不经过任何云服务器，不注册账号，不限大小，原图原码不压缩。

代码和安装包都放 GitHub 了，感兴趣可以自己拿。
